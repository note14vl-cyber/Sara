# Room Explorer 3D — Android / интерьерная сборка

Основа проекта — пустая прямоугольная комната с дверью и большим окном. Визуальный стиль: серый состаренный бетон, тёмный деревянный пол, индустриальный стол с потёртым металлом и современный тёмно-серый шкаф.

## Что есть в этой сборке
- Сохранён Android workflow GitHub Actions и настройки экспорта из предыдущего проекта.
- Кнопка `EDIT`: выбор объектов касанием, перемещение, вращение, масштабирование и изменение габаритов комнаты.
- Кнопка `LIGHTING`: установка точечных источников, изменение положения, яркости, радиуса и цвета; параметры сохраняются в `user://room_lights.json`.
- Кнопка `ПРЕДМЕТЫ`: создание бутылки и коробки перед игроком.
- Подбор/перенос/отпускание предметов с физикой, инвентарь и сохранение состояния в `user://room_items.json`.
- Сохранение размеров комнаты и трансформов объектов в `user://room_layout.json`.
- Текстуры бетона, состаренного дерева, металла и современного шкафа находятся в `textures/`.

## Управление
- `EDIT` — выбрать объект касанием, затем использовать панель перемещения/вращения/масштаба.
- `LIGHTING` — касанием поверхности поставить источник света или выбрать существующий, затем настроить его в панели.
- `ПРЕДМЕТЫ` — создать бутылку или коробку.
- `ВЗЯТЬ / ПОЛОЖИТЬ` — взять предмет перед камерой или отпустить его.
- `В ИНВЕНТАРЬ` — убрать удерживаемый предмет в инвентарь.

## Важные ограничения
- Текущая панель `LIGHTING` сохраняет параметры динамических OmniLight3D. Это ещё не запечённый LightmapGI. Для настоящего статического освещения нужно подготовить UV2/lightmap и выполнить bake в настольном редакторе Godot; готовая Android-сборка должна содержать запечённые lightmap-ресурсы.
- Изменение размеров комнаты пересоздаёт оболочку комнаты; окно и дверь пока не подгоняются автоматически под новые размеры.
- Сохранение расстановки и предметов выполняется в пользовательские файлы приложения. При удалении приложения эти данные могут быть удалены Android.
- Проект упакован, но в среде сборки не обнаружен исполняемый файл Godot, поэтому GDScript и APK здесь не запускались и не проверялись. Проверить сборку нужно через GitHub Actions.
